About This Dashboard

This dashboard provides an interactive and multi-view analysis of wildfires in mainland Portugal. Below is a summary of each page and the visualization techniques used.

🔥 Main Page

The main landing page offers a high-level overview of wildfire activity.

  • Choropleth Map – Shows total rural fires per district for the selected year. Includes hover highlight and dynamic boundaries. (Plotly)
  • Total Fires Over Time – Line chart showing annual counts of rural fires. (Plotly)
  • Burned Area by Land Type – Bar chart comparing forest, scrubland and agricultural burned area. (Plotly)
  • Fire Causes (Radar) – Mini spider chart showing aggregated causes for the selected year. (Plotly Polar)

📁 Dataset

A tabular view of the complete wildfire dataset.

  • Interactive Year Selector – Loads district-level data for the chosen year.
  • Auto-generated Table – Dynamically creates a HTML table with all available variables.

Legend of main dataset fields:

  • Ano – Year of recorded fires
  • Distrito – Administrative district
  • Num_IncendiosRurais – Number of rural fires
  • NInc_Natural / Negligente / Intencionais… – Number of fires by cause category
  • AreaArdPov / Mato / Agric – Burned area by land type
  • NIncRur_X_Yha – Fires grouped by burned area class

🔥 Burned Area Analysis

This page explores burned area patterns at both district and national scale.

  • Choropleth Map – Shows fire counts per district, with click-to-select interaction for district-specific analysis.
  • Stacked Bar Chart – Displays total burned area by land use (forest, scrub, agriculture) ordered by severity.
  • Normalized Burned Area Distribution – Stacked proportional bar chart showing the share of fires across area-burned classes (0–10 ha, 10–50 ha, etc.). Includes opacity control for classes through a slider.
  • Temporal Mode – When a district is selected, both charts switch to time-series mode.

🔥 Fire Causes Analysis

A dual-view page combining a dot plot with an interactive multi-line radar chart.

  • Dot Plot – D3.js visualization showing cause percentages per year or per district. Sorting, year filters and district filters included.
  • Spider (Radar) Chart – Multi-select visualization where the user can compare:
    • multiple years
    • multiple districts
    • or combinations year × district

    This version includes automatic resizing and fixed minimum height to prevent clipping. (Plotly Polar)
