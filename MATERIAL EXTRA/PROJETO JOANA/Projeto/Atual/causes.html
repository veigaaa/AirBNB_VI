Dot Plot – Fire Causes

i
This dot plot shows the percentage distribution of fire causes.

View: Years – each row is a year (you can filter to a single district).
View: Districts – each row is a district for the selected year.
Rows are ordered by the cause selected in Order by.

Spider Chart – Fire Causes

i
Radar chart comparing fire cause percentages.

Selection:
– You can select one or more years;
– And/or one or more districts.

If both years and districts are selected, each line represents a specific Year–District combination.
